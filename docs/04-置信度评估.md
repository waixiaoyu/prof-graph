# 04-置信度评估

## 核心理念

> **关系结果：都是直接关系（A ⇄ B）**  
> **挖掘手段：用间接手段或推导方法发现直接关系**  
> **置信度评估：每种关系都有专门的置信度计算方式**

### 价值定位

- **直接关系**：人可以直接判断的价值有限
- **潜在关系**：大模型分析擅长的点，系统核心价值
- **置信度评估**：为每种关系提供专门的置信度计算方式

---

## 第一阶段挖掘的4种直接关系

| 关系类型 | 说明 | 挖掘手段 | 价值 |
|---------|------|---------|------|
| **论文合作关系** | 共同发表过论文 | 从论文数据库直接获取 | ⭐⭐⭐ 核心 |
| **项目合作关系** | 共同参与过项目 | 从多个资讯源推断 | ⭐⭐⭐ 核心 |
| **师兄弟关系** | 同一实验室的同学、师生关系 | 从多种数据源推导 | ⭐⭐⭐ 核心 |
| **顾问关系** | 担任某机构的技术顾问、学术顾问 | 从资讯中提取 | ⭐⭐ 重要 |

---

## 1. 论文合作关系的置信度评估

### 置信度评估公式

```
置信度 = 0.4 × 姓名确信度 + 0.6 × 机构确信度
```

### 各维度确信度定义

**姓名确信度**：
| 情况 | 确信度 |
|-----|-------|
| 姓名完全匹配 | 1.0 |
| 姓名相似（如"Zhang Wei" vs "Wei Zhang"） | 0.7 |
| 姓名模糊匹配（如"李明" vs "Ming Li"） | 0.5 |
| 姓名完全不匹配但有其他证据 | 0.3 |

**机构确信度**：
| 情况 | 确信度 |
|-----|-------|
| 机构完全匹配 | 1.0 |
| 机构相似（中英文对照） | 0.8 |
| 机构模糊匹配（不同层级表述） | 0.6 |
| 机构不明确或缺失 | 0.4 |

### 置信度示例

```
案例1：姓名确信度1.0，机构确信度1.0
置信度 = 0.4×1.0 + 0.6×1.0 = 1.0（高置信度）

案例2：姓名确信度0.7，机构确信度0.8
置信度 = 0.4×0.7 + 0.6×0.8 = 0.76（中高置信度）

案例3：姓名确信度0.5，机构确信度0.4
置信度 = 0.4×0.5 + 0.6×0.4 = 0.44（低置信度）
```

## 2. 项目合作关系的置信度评估

### 核心评估维度

| 维度 | 说明 | 权重 |
|-----|------|------|
| **信息明确性** | 表达是否清晰明确 | 30% |
| **信息充分性** | 信息是否足够充分 | 30% |
| **数据源可信度** | 数据源本身的可靠性 | 20% |
| **可访问性** | 项目组成员定义的可获取性 | 20% |

### 置信度评估公式

```
置信度 = 0.3 × 信息明确性 + 0.3 × 信息充分性 + 0.2 × 数据源可信度 + 0.2 × 可访问性
```

### 各维度确信度定义

**信息明确性确信度**：
| 情况 | 确信度 | 示例 |
|-----|-------|------|
| 明确列出项目成员 | 1.0 | "项目成员：张教授、李教授、王工程师" |
| 明确说明参与关系 | 0.8 | "张教授和李教授共同参与了XX项目" |
| 暗示参与关系 | 0.5 | "张教授所在团队参与了XX项目" |
| 关系模糊 | 0.3 | "张教授与XX项目有关联" |

**信息充分性确信度**：
| 情况 | 确信度 | 示例 |
|-----|-------|------|
| 详细说明角色和时间 | 1.0 | "张教授担任项目负责人，2022-2024年" |
| 说明参与角色 | 0.8 | "张教授是该项目的核心成员" |
| 仅提及参与 | 0.5 | "张教授参与了该项目" |
| 信息较少 | 0.3 | "张教授与该项目相关" |

**数据源可信度确信度**：
| 情况 | 确信度 |
|-----|-------|
| 官方公告 | 1.0 |
| 知名媒体 | 0.8 |
| 一般资讯 | 0.6 |

**可访问性确信度**：
| 情况 | 确信度 | 示例 |
|-----|-------|------|
| 直接列出成员 | 1.0 | "项目成员：张教授、李教授" |
| 可访问到完整定义 | 0.8 | "项目组成员：见XX附件" |
| 可访问到部分定义 | 0.6 | "项目组由XX学院专家组成" |
| 定义难以获取 | 0.4 | "项目组成员由相关部门确定" |
| 定义不明确 | 0.2 | "项目组相关专家" |

### 置信度示例

```
案例1：官方公告，明确列出成员，详细说明，当前有效
置信度 = 0.3×1.0 + 0.3×1.0 + 0.2×1.0 + 0.2×1.0 = 1.0

案例2：知名媒体，明确说明参与角色，说明角色，近期关系
置信度 = 0.3×0.8 + 0.3×0.8 + 0.2×0.8 + 0.2×0.8 = 0.8

案例3：一般资讯，暗示参与关系，仅提及，时间不明确
置信度 = 0.3×0.5 + 0.3×0.5 + 0.2×0.6 + 0.2×0.5 = 0.52
```

## 3. 师兄弟关系的置信度评估

### 主要数据来源类型

| 数据源类型 | 示例 | 推断方式 |
|-----------|------|---------|
| **导师主页学生列表** | "当前学生：张三、李四、王五" | 同一导师的学生 → 同学关系 |
| **实验室成员列表** | "实验室成员：教授A、博士生B、C" | 同一实验室 → 师生/同学关系 |
| **毕业生名单** | "2020届博士毕业生：张三、李四" | 同届毕业生 → 同学关系 |
| **论文致谢** | "感谢导师XX教授和实验室同学们" | 暗示同实验室关系 |
| **直接声明** | "师从XX教授" | 直接师生关系 |

### 置信度评估公式

```
置信度 = 0.4 × 数据源可信度 + 0.3 × 关系推断确定性 + 0.2 × 信息明确性 + 0.1 × 时间吻合度
```

### 各维度确信度定义

**数据源可信度确信度**：
| 情况 | 确信度 |
|-----|-------|
| 官方列表（导师主页、实验室网站） | 1.0 |
| 半官方列表（院系网站） | 0.8 |
| 毕业生名单 | 0.8 |
| 论文致谢 | 0.6 |
| 推断信息 | 0.4 |

**关系推断确定性确信度**：
| 情况 | 确信度 | 示例 |
|-----|-------|------|
| 明确在同一列表中 | 1.0 | 两人都在"当前学生"列表中 |
| 明确在同一类别中 | 0.9 | 两人都在"博士生"类别中 |
| 暗示同实验室 | 0.7 | 致谢中提到"实验室同学" |
| 推断可能有关联 | 0.5 | 同一导师的不同时期学生 |

**信息明确性确信度**：
| 情况 | 确信度 | 示例 |
|-----|-------|------|
| 明确分类和身份 | 1.0 | "博士生：张三、李四" |
| 明确身份 | 0.8 | "实验室成员：张三、李四" |
| 仅列出名字 | 0.6 | "团队成员：张三、李四、王五" |
| 名字模糊 | 0.4 | "相关研究人员" |

**时间吻合度确信度**：
| 情况 | 确信度 |
|-----|-------|
| 时间明确且吻合 | 1.0 |
| 时间接近 | 0.7 |
| 时间不明确 | 0.5 |
| 时间不吻合 | 0.2 |

### 置信度示例

```
案例1：官方列表，明确在同一列表中，明确分类，时间吻合
置信度 = 0.4×1.0 + 0.3×1.0 + 0.2×1.0 + 0.1×1.0 = 1.0

案例2：实验室网站，明确在同一类别中，明确身份，时间接近
置信度 = 0.4×1.0 + 0.3×0.9 + 0.2×0.8 + 0.1×0.7 = 0.88

案例3：论文致谢，暗示同实验室，仅列出名字，时间不明确
置信度 = 0.4×0.6 + 0.3×0.7 + 0.2×0.6 + 0.1×0.5 = 0.63
```

## 4. 顾问关系的置信度评估

### 置信度评估公式

```
置信度 = 0.4 × 信息明确性 + 0.3 × 数据源可信度 + 0.2 × 信息充分性 + 0.1 × 时效性
```

### 各维度确信度定义

**信息明确性确信度**：
| 情况 | 确信度 | 示例 |
|-----|-------|------|
| 明确说明顾问角色 | 1.0 | "担任XX公司首席技术顾问" |
| 明确说明专家角色 | 0.8 | "担任XX公司技术专家委员会委员" |
| 暗示顾问关系 | 0.5 | "为XX公司提供技术咨询" |
| 关系模糊 | 0.3 | "与XX公司有合作关系" |

**数据源可信度确信度**：
| 情况 | 确信度 |
|-----|-------|
| 官方公告（企业/高校官网） | 1.0 |
| 知名媒体 | 0.8 |
| 一般资讯 | 0.6 |
| 社交媒体 | 0.4 |

**信息充分性确信度**：
| 情况 | 确信度 | 示例 |
|-----|-------|------|
| 详细说明角色和期限 | 1.0 | "2022-2025年担任首席技术顾问" |
| 说明角色 | 0.8 | "担任技术顾问" |
| 仅提及关系 | 0.5 | "与XX公司有顾问关系" |
| 信息较少 | 0.3 | "为XX公司提供咨询" |

**时效性确信度**：
| 情况 | 确信度 | 示例 |
|-----|-------|------|
| 明确当前有效 | 1.0 | "现任首席技术顾问" |
| 明确近期关系 | 0.8 | "2023年担任技术顾问" |
| 关系时间不明确 | 0.5 | "曾担任技术顾问" |
| 历史关系 | 0.3 | "2015年曾任技术顾问" |

### 置信度示例

```
案例1：官方公告，明确说明顾问角色，详细说明，当前有效
置信度 = 0.4×1.0 + 0.3×1.0 + 0.2×1.0 + 0.1×1.0 = 1.0

案例2：知名媒体，明确说明专家角色，说明角色，近期关系
置信度 = 0.4×0.8 + 0.3×0.8 + 0.2×0.8 + 0.1×0.8 = 0.8

案例3：一般资讯，暗示顾问关系，仅提及，时间不明确
置信度 = 0.4×0.5 + 0.3×0.6 + 0.2×0.5 + 0.1×0.5 = 0.53
```

## 置信度评估总结

| 关系类型 | 核心评估维度 | 权重分配 |
|---------|-------------|---------|
| **论文合作** | 姓名确信度、机构确信度 | 0.4姓名 + 0.6机构 |
| **项目合作** | 信息明确性、信息充分性、数据源可信度、可访问性 | 0.3明确 + 0.3充分 + 0.2可信 + 0.2可访问 |
| **师兄弟关系** | 数据源可信度、关系推断确定性、信息明确性、时间吻合度 | 0.4数据源 + 0.3推断 + 0.2明确 + 0.1时间 |
| **顾问关系** | 信息明确性、数据源可信度、信息充分性、时效性 | 0.4明确 + 0.3数据源 + 0.2充分 + 0.1时效 |

### 置信度分级（统一标准）

| 置信度范围 | 分类 | 处理方式 |
|-----------|------|---------|
| 0.8-1.0 | 高置信度 | 正常显示 |
| 0.5-0.7 | 中置信度 | 标注"待确认" |
| 0.3-0.4 | 低置信度 | 标注"低可信"或默认隐藏 |
| < 0.3 | 极低置信度 | 默认隐藏，需要人工确认 |
