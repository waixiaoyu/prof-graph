# 05-前端界面设计

## 核心页面结构

| 页面 | 功能 | 优先级 |
|-----|------|-------|
| **图谱主页** | 关系网络可视化、节点展开、搜索 | P0 |
| **搜索页** | 按姓名、机构、研究方向搜索 | P0 |
| **管理后台** | 手动修正实体和关系 | P0 |
| **数据监控** | 显示数据更新状态、最近新增实体 | P1 |

## 图谱主页设计

### 核心功能

1. **大规模节点支持**：支持 1000+ 节点展示
2. **过滤能力**：按关系类型、机构、研究方向过滤
3. **节点展开**：点击节点显示其合作关系
4. **搜索定位**：搜索后高亮显示相关节点
5. **缩放拖拽**：自由导航图谱

### 交互示例

```
搜索"张教授" → 高亮显示张教授节点
  → 点击张教授节点 → 展开其合作关系
  → 显示合作者列表 + 合作论文证据
```

### 过滤选项

- **按机构过滤**：只显示某高校的人员网络
- **按关系类型过滤**：只显示论文合作 / 项目合作 / 学术传承 / 潜在连接
- **按研究方向过滤**：只显示某领域的人员
- **按置信度过滤**：隐藏低置信度关系（如 < 0.5）

### 潜在连接的展示 ⭐

> 潜在关系在图谱中以**虚线/不同颜色**与直接关系区分展示，让用户一眼区分"已验证关系"和"推断关系"。

| 展示要素 | 说明 |
|---------|------|
| **视觉区分** | 直接关系用实线，潜在连接用虚线（或浅色） |
| **发现方法标签** | 悬浮显示是 common_network / research_similarity / spatiotemporal 哪种方法发现 |
| **推断依据** | 点击潜在连接可查看支持信号（如共同合作者数量、研究相似度分数、时空重叠） |
| **置信度展示** | 标注潜在连接的置信度（一般低于直接关系） |

### 图谱展示能力

| 展示需求 | 实现方式 |
|---------|---------|
| 大规模节点 | 节点聚合 + 分层展示 |
| 节点展开 | 点击节点 → 展开其合作关系 |
| 关系过滤 | 按类型、机构、研究方向、置信度过滤 |
| 直接/潜在区分 | 实线（直接） vs 虚线（潜在） |

## 搜索功能设计

### 双模式展示

- **图谱模式**：搜索结果在图谱中高亮显示
- **列表模式**：搜索结果以列表形式展示详细信息

### 搜索维度

- **按姓名搜索**：支持模糊匹配
- **按机构搜索**：搜索高校/院系/实验室
- **按研究方向搜索**：搜索技术领域标签
- **组合搜索**：多条件组合查询

### 搜索结果展示

| 模式 | 说明 | 优势 |
|-----|------|------|
| **图谱模式** | 在图谱中高亮显示相关节点 | 直观看到关系网络 |
| **列表模式** | 以列表形式展示详细信息 | 便于查看具体信息 |

## 管理后台设计

### 定位

**管理员专用功能，不需要特别美观**

### 核心功能

1. **修正姓名/机构名**：修正实体识别错误
2. **添加/删除关系**：手动调整关系
3. **修改研究方向**：更新研究方向标签
4. **合并重复实体**：处理实体消歧问题

### 实现方式

- 单独的编辑页面
- 表单化操作界面
- 操作日志记录

### 编辑功能范围

| 功能 | 说明 | 优先级 |
|-----|------|-------|
| **修正姓名/机构名** | 修正实体识别错误 | 必须 |
| **添加/删除关系** | 手动调整关系 | 必须 |
| **修改研究方向** | 更新研究方向标签 | 必须 |
| **合并重复实体** | 处理实体消歧问题 | 必须 |
| **消歧审核队列** | 处理中置信度（0.5-0.8）的待审核合并建议，人工确认/拒绝 | 必须 |
| **失败任务重跑** | 查看死信队列中的失败抽取任务，支持手动重跑 | 必须 |
| **立即更新** | 手动触发数据抓取 + GLM 抽取任务，实时显示进度 | 必须 |

## 数据监控页面设计

### 功能定位

**显示数据更新状态和最近新增实体**

### 核心功能

1. **数据更新状态**：显示最近一次数据更新时间和状态
2. **最近新增实体**：显示最近新增的人员、关系
3. **系统健康状态**：显示系统运行状态

### 展示内容

| 内容类型 | 说明 |
|---------|------|
| **数据更新状态** | 最近一次更新时间、更新状态、新增数据量 |
| **最近新增实体** | 最近新增的人员、论文、关系 |
| **系统健康状态** | API状态、数据库状态、GLM调用状态 |

## 界面交互设计原则

### 核心原则

1. **以人为中心**：围绕人员展开关系网络
2. **证据可见**：每个关系都能看到证据链
3. **置信度展示**：清晰标注关系的置信度
4. **操作简单**：核心功能一键操作

### 交互流程

```
用户进入系统 → 看到图谱主页
  → 搜索某个专家 → 在图谱中高亮显示
  → 点击专家节点 → 展开其合作关系
  → 查看某个关系 → 查看证据链详情
  → 如有错误 → 进入管理后台修正
```
