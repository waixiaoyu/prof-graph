## 1. 背景与目标

M1/M2/M2.5/M3 交付后，生产运行暴露四类稳定性/数据质量问题（2026-08-25~31 夜批事故与库审计）：

1. **机构实体不归一**：同一真实机构以不同表面串入库成多行（分号/逗号变体、全角/半角括号、尾部国家词），让消歧 org 打分假性失配——复核队列里 181 条"分号变体"类假相异，另有多机构拼接垃圾行与缩写/全称并存（IPADS×4、NISL×3）。
2. **批量复核缺工具**：复核队列峰值 2,484 条，人工逐条点不现实；证据确凿子集需规则化批量预处置（已按"同名+≥2 共同作者+机构不矛盾"证据标准执行 443 条合并），剩余弱证据条目需要批量复核 UI。
3. **批次可观测性缺失**：夜批失败 5 夜无人知晓（批次状态只在内存、无告警）；失败重试已有 failed_jobs 骨架，缺看板。
4. **消费端体验债**：图谱搜索中文未走拼音归一等。

本里程碑按"先止血数据、再补工具、后加观测"排序交付。

## 2. 机构消解（第一刀，已实现 ✅ 2026-08-31）

### 2.1 规则（只收零风险等价类）

`org_key`（`app/services/org_resolution.py`，写入侧 upsert / 图谱搜索 / 消解重写三处同键）：

- **R1 标点塌缩**：`;` `；` `,` `，` `(` `)` `（` `）` `-` `&` `/` 一律当空格，`.` 删除，小写，去通用机构词（university/institute/lab/school/college/academy）后 token 序列相同 → 同键；
- **R2 尾部地理词剥离**：仅国家 + 省份词（china/usa/guangdong/…），**绝不剥城市词**；且剩余部分须含 ≥1 个长度 ≥4 的非通用词（残基守卫：`Bank of China` 不剥成 `bank of`，否则与 `Bank of England` 撞键）。

**明确不做**（需要 OpenAlex institution id / 人工别名表，后续小节）：
- 城市/校区词剥离——校区是机构身份的一部分（哈工大≠哈工大深圳、HKUST≠HKUST-广州、CUHK≠CUHK-深圳）；
- 多机构拼接串拆分（"NUS; Zhejiang University" 现按第一机构并入，各 1 引用，可接受）；
- 缩写↔全称（IPADS↔并行与分布式系统研究所）。

### 2.2 不变量

- 合并执行单事务：PersonOrg 迁移（同人同机构置信度取大）→ 删被并行 → 全量键重写；RD-7 审计日志（`admin_edits.action=merge_orgs`，entity_type=organization，前后快照配对）。
- 新插入侧 `upsert_organization` 用同一 `org_key`，变体不复活；已重写存量 3,526 行键。
- 校区不并：上述三组校区对键必不相等（测试锁定）。

### 2.3 生产结果（2026-08-31）

6050 → 5826 行（206 簇并 224 行，514 条人-机构归属迁移）；复核队列解锁 A 桶合并 32 条（累计证据合并 443 条）；巡检 C1-C11 全绿；带国家后缀的机构串可命中图谱 org 筛选。

### 2.4 后续（待排期）

- **机构规范化第二刀**：论文 authorships 的 `institutions[].id`（OpenAlex institution id）作为机构强键入库（对应 persons.openalex_id 的地位），校区/别名随权威库解决；辅以人工别名表（IPADS/NISL 等中文实验室缩写）。
- **多机构拼接串拆分**：`A; B` 串按分号拆开逐段挂接（拆分需先过 org_key 判别段是机构还是地址）。
